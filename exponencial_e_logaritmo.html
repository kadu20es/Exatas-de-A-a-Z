O que é uma Potência?

A potenciação é uma forma rápida de escrever multiplicações repetidas do mesmo número. Se multiplicarmos o 2 por ele mesmo três vezes, escrevemos \(2^3\).

\[\textcolor{#2563eb}{2}^{\textcolor{#dc2626}{3}} = \textcolor{#2563eb}{2} \times \textcolor{#2563eb}{2} \times \textcolor{#2563eb}{2} = \textcolor{#059669}{8}\]
Base (2)
O número que será multiplicado.
Expoente (3)
Quantas vezes a base aparece.
Potência (8)
O resultado final.
2

Expoentes Especiais

Nem sempre o expoente é um número positivo simples. Veja o que acontece nos casos especiais:

Expoente Zero: Qualquer número (exceto zero) elevado a 0 é 1.
\[5^0 = 1\]
Expoente Negativo: Inverte a base. É o "oposto" de multiplicar.
\[2^{-3} = \frac{1}{2^3} = \frac{1}{8}\]
Expoente Fracionário: Transforma a potência em uma raiz.
\[9^{\frac{1}{2}} = \sqrt{9} = 3\]
3

O que é o Logaritmo?

O logaritmo é o caçador de expoentes. Enquanto na potência você tem a base e o expoente para descobrir o resultado, no logaritmo você tem a base e o resultado e precisa descobrir o expoente.

Quando você lê a expressão:

\[\log_{\textcolor{#2563eb}{2}} \textcolor{#059669}{8} = \textcolor{#dc2626}{?}\]

Seu cérebro deve perguntar automaticamente:

"A base 2 elevada a qual número resulta em 8?"

Como \(\textcolor{#2563eb}{2}^{\textcolor{#dc2626}{3}} = \textcolor{#059669}{8}\), a resposta é 3.
\[\log_{2} 8 = 3\]

4

O Ciclo Fundamental

A relação mais importante da matemática para este assunto é a conversão direta entre logaritmo e exponencial. Memorize este movimento cíclico:

\[\log_b a = c \iff b^c = a\]
A Regra do "Empurrão": A base do logaritmo (o pequenininho) passa para o outro lado "empurrando" o resultado para o expoente.
5

Condições de Existência

Os logaritmos não funcionam com qualquer número. Para calcular \(\log_b a\), três regras de ouro devem ser seguidas:

Base positiva: \(b > 0\). Não existe logaritmo de base negativa nos reais.
Base diferente de 1: \(b \neq 1\). Se a base fosse 1, \(1^x\) daria sempre 1, não gerando outros números.
Logaritmando positivo: \(a > 0\). O número do qual queremos extrair o logaritmo tem que ser maior que zero (não existe potência real de base positiva que dê resultado negativo).
6

Logaritmos Famosos

Dois logaritmos aparecem com tanta frequência que ganharam "apelidos" e notações especiais. Quando você não vir a base escrita, assuma um desses dois:

Logaritmo Decimal

\[\log 100 \implies \log_{10} 100\]

Quando não houver base, a base é 10. É muito usado em cálculos de química (pH), som (decibéis) e terremotos (Escala Richter).

Logaritmo Natural

\[\ln x \implies \log_{e} x\]

O "ln" significa logaritmo na base e (Número de Euler, \(e \approx 2.718\)). É a base universal do crescimento na biologia e economia.

7

As 3 Propriedades de Ouro

Como o logaritmo "desce" um nível operacional (transforma potência em multiplicação), ele faz o mesmo com outras operações:

1. Produto vira Soma
\[\log_b (x \cdot y) = \log_b x + \log_b y\]
2. Divisão vira Subtração
\[\log_b \left(\frac{x}{y}\right) = \log_b x - \log_b y\]
3. Potência vai para frente (Tombo)
\[\log_b (x^k) = k \cdot \log_b x\]
8

Mudança de Base

E se a sua calculadora só tem logaritmo na base 10, mas você precisa de \(\log_2 7\)? Você divide o log do de cima pelo log do de baixo, na base que quiser (como a 10):

\[\log_{\textcolor{#dc2626}{a}} \textcolor{#2563eb}{b} = \frac{\log_c \textcolor{#2563eb}{b}}{\log_c \textcolor{#dc2626}{a}} \implies \log_2 7 = \frac{\log 7}{\log 2}\]
9

Equações Exponenciais

Se a incógnita \(x\) está no expoente (ex: \(2^x = 16\)), seu objetivo número um é igualar as bases dos dois lados.

Passos:
1. Fatore o 16: \(16 = 2^4\).
2. Substitua: \(2^x = 2^4\).
3. Corte as bases: \(x = 4\).
10

Checklist para Exercícios

① É Equação?
Tente igualar as bases primeiro. Se não der, aplique log dos dois lados.
② É Log simples?
Use a regra do empurrão: a base do log empurra o resultado e vira expoente.
③ Tem operações?
Soma de logs vira produto; subtração vira divisão. Aplique de trás pra frente.
④ Confira (C.E.)
Achou o \(x\)? Verifique se ele não deixa base ou logaritmando negativos ou zero.
